# Projetos Praticos

Aqui você vai construir programas completos. A ideia é juntar tudo que você aprendeu e criar algo que funciona de verdade, não só exercícios isolados.

**Pré-requisitos:** todas as seções anteriores.

## O que tem aqui

### Calculadoras (01_Calculadoras)

Programas pequenos com propósito específico:
- IMC (Índice de Massa Corporal)
- Bhaskara (equação do segundo grau)
- Sorteio aleatório

### Jogos (02_Jogos)

Projetos interativos que usam laços, condicionais, listas e funções:
- Adivinhação de número
- Pedra, papel e tesoura
- Forca
- Jogo da velha
- Blackjack
- Termoo (estilo Wordle)

### Sistemas (03_Sistemas)

A parte mais próxima de um software real.

- `Implementacoes/` - sistemas prontos para você estudar como foram feitos
- `Propostas/` - 9 especificações detalhadas de sistemas para você implementar do zero

Cada proposta em `Propostas/` descreve o que o sistema deve fazer, quais dados guardar e quais operações realizar. Escolha uma e tente construir sem olhar as implementações prontas.

## Dica

Os jogos são uma boa forma de aprender a organizar código em funções. Antes de rodar o programa, leia o código inteiro e tente entender o fluxo.
