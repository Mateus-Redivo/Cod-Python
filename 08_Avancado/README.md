## O que tem aqui

### Padroes_De_Projeto

Design Patterns são soluções reutilizáveis para problemas comuns no design de software. Não são sobre lógica básica, mas sobre como organizar código em programas maiores.

Os padrões incluídos aqui:

- `Builder` - separar a construção de um objeto complexo da sua representação
- `Factory` - criar objetos sem especificar a classe concreta
- `Strategy` - definir uma família de algoritmos e torná-los intercambiáveis
- `Padrao` - exemplo base de estrutura de padrão

**Pré-requisito real para entender isso:** ter trabalhado com programas maiores, entender funções bem, e de preferência ter visto conceitos básicos de orientação a objetos.
