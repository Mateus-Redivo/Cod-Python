# Revisao e Listas

Material de revisão com exercícios mais exigentes, focados em leitura e análise de código, refatoração e funções.

**Pré-requisitos:** todas as seções anteriores.

## O que tem aqui

### Cognitivo

Exercícios de análise de código. Cada arquivo da pasta `Base/` apresenta um código com problemas de clareza ou estrutura. O objetivo é entender o que o código faz e propor melhorias. A pasta `Refatorado/` mostra uma versão corrigida de cada um.

Os temas abordados nos exercícios:
- `01_calculo_precos` - cálculo com impostos e descontos
- `02_processamento_clientes` - processamento de dados de clientes com descontos
- `03_calculo_seguro` - cálculo de prêmio de seguro com múltiplos critérios
- `04_status_pets` - pontuação de pets com regras e bônus
- `05_notas_estudantes` - cálculo de nota com bônus e políticas de recuperação

### Funcoes e Procedimentos

Lista com 20 exercícios sobre funções, do básico ao intermediário. O arquivo `_aluno.py` tem os cabeçalhos prontos para você completar. O arquivo `_resolucao.py` tem as soluções.

### Listas

Exercícios adicionais de listas com análise de código e refatoração de soluções já existentes.

### Matrizes

Lista de exercícios focados em operações com matrizes.

### Extras

- `Comentarios.md` - guia sobre como escrever comentários no código de forma útil (TODO, FIXME, WARNING, etc.)
