# Estruturas de Controle

Aqui o foco é aplicar o que foi aprendido nos fundamentos em programas um pouco mais completos. Os exemplos usam calculadoras como fio condutor para mostrar como o mesmo problema pode ser resolvido com diferentes estruturas.

**Pré-requisitos:** 01_Fundamentos_Python completo.

## O que você vai encontrar

- `01_Condicionais` - calculadora construída com `if`/`elif`/`else`
- `02_Loops` - a mesma calculadora, agora com laço de repetição para continuar calculando
- `03_Match_Case` - versão usando `match/case`, recurso do Python 3.10 em diante

## Por que ver isso depois dos fundamentos?

Os fundamentos ensinam as peças. Aqui você começa a montar programas que têm menu, repetem ações e tomam decisões mais elaboradas. É uma ponte entre aprender a sintaxe e escrever código que resolve algo de verdade.
