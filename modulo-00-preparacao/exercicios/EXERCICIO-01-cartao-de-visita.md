# Exercício 01 — Cartão de visita

| Nível | Tempo estimado | Conceitos |
| --- | --- | --- |
| 1 de 3 | 15 min | `print`, comentários, executar um arquivo |

## Objetivo

Escrever, do zero, o seu primeiro programa Python e conseguir rodá-lo pelo terminal.

## Requisitos

1. Crie um arquivo chamado `cartao_de_visita.py`.
2. O programa deve mostrar na tela: seu nome, sua cidade e uma frase sobre por que você está
   estudando programação.
3. Use uma linha em branco (`print()`) para separar o nome do resto.
4. Escreva pelo menos um comentário explicando alguma escolha sua: não vale comentar o óbvio.
5. Rode o arquivo **pelo terminal**, com `python cartao_de_visita.py`. O botão do VS Code também
   funciona, mas o objetivo aqui é você conseguir pelos dois caminhos.

## Exemplo de saída

```text
=================================
Maria Oliveira

Cidade: Cascavel - PR
Estudo Python para automatizar os relatórios do meu trabalho.
=================================
```

O conteúdo é seu; o formato pode variar. O que não pode faltar são as três informações e a linha
em branco.

## Critérios de aceitação

- [ ] O arquivo se chama `cartao_de_visita.py` e roda sem erro
- [ ] Aparecem nome, cidade e o motivo de estudar
- [ ] Existe pelo menos um `print()` vazio separando blocos
- [ ] Existe pelo menos um comentário, e ele explica algo não óbvio
- [ ] Você rodou pelo terminal ao menos uma vez

## Desafio opcional

Provoque um erro de propósito no seu programa: apague uma aspa, por exemplo. Anote em um
comentário: qual linha o Python apontou e qual foi o tipo do erro. Depois conserte.
