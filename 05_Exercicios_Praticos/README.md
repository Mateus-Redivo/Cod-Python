# Exercicios Praticos

Hora de colocar tudo em prática. Os exercícios aqui estão separados por nível de dificuldade e cobrem os temas das seções anteriores.

**Pré-requisitos:** 01, 02 e 03 completos.

## Níveis de dificuldade

### Iniciante (01_Nivel_Iniciante)

8 exercícios que usam listas, laços e condicionais básicos. Bom ponto de partida para quem está revisando.

- Soma de elementos, média de notas
- Contar positivos e negativos
- Filtrar pares e ímpares
- Inverter lista, tabuada, sequência de Fibonacci

### Intermediário (02_Nivel_Intermediario)

Exercícios que exigem um pouco mais de raciocínio sobre a estrutura dos dados.

- Encontrar menor e maior valor
- Encontrar o segundo maior número

### Avançado (03_Nivel_Avancado)

Programas mais completos que simulam situações reais.

- Sistema de cadastro de notas
- Controle de produtos

## Como usar essa seção

Tente resolver cada exercício antes de olhar qualquer solução. Se travar, releia o código das seções anteriores que abordam aquele tema.
