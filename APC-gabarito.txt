GABARITO - LISTA DE ESTUDOS - ALGORITMOS E PROGRAMAÇÃO DE COMPUTADORES
3º Bimestre

01. Saída: 15. Primeiro somar_um(4) é executado e retorna 5; esse valor 5
é passado para triplicar(), que retorna 5 * 3 = 15.

02. O Python lança um TypeError, pois foram passados mais argumentos
posicionais do que a função aceita parâmetros com valor padrão não
aumentam a quantidade de argumentos posicionais permitidos.

03. Porque depender de variáveis globais deixa o comportamento da função
escondido e difícil de prever outra parte do código pode alterar a
variável a qualquer momento. Receber valores como parâmetro e devolver
com return deixa a função previsível: "entra valor, sai valor".

04. Ocorre um NameError, porque desconto é uma variável local, criada
dentro de calcular_desconto(); ela deixa de existir assim que a função
termina de executar.

05. Diferença: 2.25. A função retorna média (31/4 = 7.75) e maior nota
(10); a diferença impressa é 10 - 7.75 = 2.25.

06. O corpo da função só é executado quando ela é chamada; a definição
(def) apenas "ensina" o Python a reconhecer a função, sem rodar o código
interno. Os comandos fora de qualquer função são executados na ordem em
que aparecem no arquivo, de cima para baixo.

07. Não gera erro. Python não verifica os tipos dos argumentos
posicionais nesse tipo de chamada a ordem importa e é ela que define
qual valor vai para qual parâmetro. Aqui, curso recebe "Ana", aluno
recebe 16 e idade recebe "Python", resultando numa frase sem sentido,
mas sem erro de execução.

08. Porque print() sempre devolve None; se essa variável for usada
depois numa operação matemática ou comparação com um número, o Python
lança um TypeError, pois não é possível operar None com um número.

09. Ocorre um UnboundLocalError. Como há uma atribuição a saldo dentro
da função (saldo = saldo + valor), o Python trata saldo como uma
variável local a partir desse ponto; ao tentar usá-la do lado direito
antes de ela ter um valor local definido, o erro ocorre.

10. cidade recebe seu valor padrão, "Não informado", porque nenhum
argumento foi passado especificamente para ela nessa chamada (ativo foi
passado por nome, mas isso não afeta cidade).

11. Variável local existe apenas dentro da função onde foi criada e
deixa de existir quando a função termina; variável global é criada fora
de qualquer função e pode ser lida de dentro de funções (mas não
alterada sem a palavra-chave global). Exemplo: um contador definido fora
das funções é global; uma variável criada dentro de uma função é local
a ela.

12. Porque ao atribuir um valor a uma variável dentro de uma função, o
Python passa a tratá-la como local àquela função a partir do início do
bloco; se o código tentar ler o valor dela antes dessa atribuição
(achando que é a variável global), o Python não encontra um valor local
ainda definido e gera o erro. Declarar global antes resolve, pois avisa
o Python para usar a variável externa.
