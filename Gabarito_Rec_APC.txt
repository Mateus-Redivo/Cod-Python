Gabarito — Lista de Questões — Tópicos Gerais de Python
============================================================

1. Saída no terminal: PYTHON6
   - x = "Python" cria uma string.
   - x.upper() retorna "PYTHON" (converte todos os caracteres para maiúsculas, sem
     alterar a variável original).
   - len(x) retorna 6 (a quantidade de caracteres de "Python").
   - str(len(x)) converte o número 6 na string "6", pois não é possível concatenar
     string com int usando +.
   - A concatenação "PYTHON" + "6" resulta em "PYTHON6".

2. Tipagem dinâmica significa que não declaramos o tipo das variáveis; o interpretador
   determina o tipo automaticamente em tempo de execução, e uma mesma variável pode
   receber valores de tipos diferentes ao longo do programa.
   - type("42") retorna <class 'str'>, pois "42" está entre aspas (é texto).
   - type(42) retorna <class 'int'>, pois 42 é um número inteiro.
   - Diferença: "42" é uma sequência de caracteres (texto) e 42 é um valor numérico
     com o qual podemos fazer operações aritméticas diretamente.

3. Parâmetros com valor padrão (default) são parâmetros que já possuem um valor
   definido na assinatura da função; se o argumento não for informado na chamada, o
   valor padrão é usado.
   - Em saudacao("Carlos"), apenas nome recebe "Carlos" e msg assume o padrão "Olá".
   - Saída: Olá, Carlos!

4. Tipo do resultado: float (<class 'float'>).
   - int("15") converte a string "15" no inteiro 15.
   - float("3.5") converte a string "3.5" no número de ponto flutuante 3.5.
   - Na soma int + float, o Python promove (converte automaticamente) o inteiro para
     float para preservar a parte decimal, resultando em 18.5, que é do tipo float.
   - print(type(resultado)) exibe <class 'float'>.

5. O método split() divide uma string em uma lista de substrings; sem argumentos, ele
   usa os espaços em branco como separador.
   - palavras = ["aprender", "python", "é", "divertido"] (4 elementos).
   - len(palavras) imprime 4.

6. pop() remove e retorna um elemento da lista, alterando a própria lista.
   - pop() sem argumento remove e retorna o ÚLTIMO elemento.
   - pop(0) remove e retorna o PRIMEIRO elemento (índice 0).
   Exemplo:
   lista = [10, 20, 30]
   lista.pop()    -> retorna 30; lista fica [10, 20]
   lista.pop(0)   -> retorna 10; lista fica [20]

7. Diferença entre // e %:
   - // é a divisão inteira (floor): retorna o quociente sem a parte decimal.
   - % é o módulo: retorna o resto da divisão.
   - Para x = 5 e y = 2: 5 // 2 = 2 (quociente) e 5 % 2 = 1 (resto).
   - Saída: 2 1

8. Comentários servem para documentar e explicar o código, tornando-o mais legível,
   sem influenciar a execução (são ignorados pelo interpretador).
   - São escritos com # para comentários de uma linha; também é comum usar strings de
     várias linhas (''' ''' ou """ """) como docstrings.
   - Não afetam a execução do programa.
   - Boas práticas: explicar o "porquê" e não o óbvio, manter comentários atualizados,
     ser claro e conciso, usar docstrings para descrever funções/classes.

9. O método replace() retorna uma nova string substituindo todas as ocorrências de um
   trecho por outro (a string original é imutável).
   - "hello".replace("l", "r") troca cada "l" por "r", gerando "herro".
   - Como s recebe o resultado, o valor final de s é "herro".
   - Saída: herro

10. Uma função é um bloco de código reutilizável que executa uma tarefa e pode receber
    entradas e retornar um resultado.
    - Parâmetro é a variável declarada na definição da função (ex.: n).
    - Argumento é o valor real passado na chamada (ex.: 7).
    Passo a passo:
    - dobro(7) chama a função com argumento 7, então n = 7.
    - return n * 2 calcula 7 * 2 = 14 e retorna esse valor.
    - resultado recebe 14.
    - print(resultado) imprime 14.

11. O operador in verifica se um elemento pertence a uma sequência (lista, string,
    etc.), retornando True ou False.
    - "banana" in frutas -> True (banana está na lista).
    - "laranja" in frutas -> False (laranja não está na lista).
    - Saída:
      True
      False

12. range() gera uma sequência de números. Seus três argumentos são:
    - início (start): valor inicial (inclusivo); padrão 0.
    - fim (stop): valor final (exclusivo) — obrigatório.
    - passo (step): incremento entre os valores; padrão 1.
    - range(2, 10, 2) gera 2, 4, 6, 8 (o 10 não entra por ser exclusivo).
    - Iterações: total = 0+2=2, depois 2+4=6, depois 6+6=12, depois 12+8=20.
    - Saída: 20

13. continue interrompe a iteração atual e pula para a próxima do laço, sem encerrá-lo.
    - Diferença para break: o break encerra completamente o laço; o continue apenas
      ignora o restante daquela iteração e continua o laço.
    - range(1, 8) gera 1 a 7. Quando i % 3 == 0 (ou seja, 3 e 6), o continue pula o
      print. Os demais são impressos.
    - Saída:
      1
      2
      4
      5
      7

14. O laço while repete um bloco enquanto sua condição for verdadeira.
    - while com condição normal: testa a condição antes de cada repetição e termina
      quando ela se torna falsa.
    - while True com break: a condição é sempre verdadeira (loop "infinito"), e a saída
      é controlada por um break dentro do laço.
    Execução:
    - contador começa em 10.
    - 10-3=7 (>=0, não sai); 7-3=4; 4-3=1; 1-3=-2 -> -2 < 0, executa break.
    - O laço termina quando contador fica negativo.
    - Saída: -2

15. Fatiamento (slicing) extrai uma sublista a partir de uma lista.
    - Sintaxe geral: lista[início:fim:passo].
    - início: índice inicial (inclusivo); fim: índice final (exclusivo); passo:
      intervalo entre os elementos selecionados.
    - dados[1:6:2] começa no índice 1 (20), vai até o índice 5 (índice 6 excluído) e
      pula de 2 em 2: índices 1, 3, 5 -> 20, 40, 60.
    - Saída: [20, 40, 60]

16. Indexação negativa permite acessar elementos a partir do final da sequência: -1 é
    o último, -2 o penúltimo, e assim por diante.
    - cores[-1] -> "branco" (último elemento).
    - cores[-3] -> "azul" (terceiro a partir do fim: branco=-1, amarelo=-2, azul=-3).
    - Saída:
      branco
      azul
