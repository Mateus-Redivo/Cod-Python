## Como usar isto

Estes programas **não seguem o padrão** dos módulos: não têm README próprio, não têm exercícios e
o estilo varia. Eles são material anterior à reestruturação, mantidos porque funcionam e valem a
pena.

Duas formas de aproveitá-los:

1. **Jogue primeiro.** Rode, use, tente quebrar. Depois abra o código e reconheça o que você já sabe.
2. **Use como exercício de leitura.** Cada um deles serve para o
   [exercício 01 do módulo 12](../modulo-12-leitura-e-refatoracao/exercicios/EXERCICIO-01-lendo-codigo-alheio.md):
   descrever o que faz sem rodar, e apontar o que melhoraria.

O jogo da velha tem uma implementação comentada como
[gabarito do módulo 09](../gabaritos/modulo-09-ex03-jogo-da-velha/) — compare as duas.
