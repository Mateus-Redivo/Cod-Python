# Banco de exercícios

Prática extra, para quando os três exercícios de um módulo não bastaram.

Estes exercícios **não fazem parte da trilha**. Nenhum módulo depende deles, e ninguém precisa
fazê-los para avançar. Eles existem para quem terminou um módulo e quer mais repetição antes de
seguir — ou para quem voltou meses depois e quer se testar.

## Como estão organizados

| Pasta | Para quem |
| --- | --- |
| `nivel-1-iniciante/` | terminou os módulos 01 a 04 |
| [nivel-2-intermediario/](nivel-2-intermediario/) | terminou os módulos 05 a 07 |
| `nivel-3-avancado/` | terminou os módulos 08 a 11 |

Cada enunciado diz, no rodapé, qual módulo você precisa ter feito antes.

## Antes de vir para cá

Faça os exercícios do módulo primeiro. Eles são escolhidos para cobrir exatamente o que a aula
ensinou, na ordem em que ensinou. O banco é reforço, não substituto.

As resoluções ficam em [gabaritos/](../gabaritos/), com as mesmas regras de sempre: tente por
vinte minutos antes de abrir.
