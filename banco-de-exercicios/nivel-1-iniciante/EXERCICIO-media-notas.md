# Média de notas

| Nível | Tempo estimado | Conceitos |
| --- | --- | --- |
| Iniciante | 10 min | lista, `float`, média, formatação com duas casas |

## O que fazer

Leia 5 notas do usuário e exiba a média aritmética delas, com duas casas decimais.

As notas podem ter parte decimal (`7.5`), então não leia como inteiro.

## Exemplo de saída

```text
Digite uma nota: 7.5
Digite uma nota: 8
Digite uma nota: 6.25
Digite uma nota: 9
Digite uma nota: 5.5
Média das notas: 7.25
```

## Critérios de aceitação

- [ ] Notas com casas decimais são aceitas
- [ ] A média sai com exatamente duas casas decimais
- [ ] A divisão usa a quantidade de notas, não o número 5 escrito na mão
